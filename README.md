# Lambda 线路实验室

当前源码及大厅资源版本：**0.3.9**。许可证：[MIT](LICENSE)。新版由[游戏大厅](https://github.com/xiaoxuhui/game-hub/releases)统一发行；独立 APK 保留历史版本 0.3.3。

示例菜单新增「布尔逻辑与电路」：20个示例覆盖基本门、异或／同或、半加器／全加器、选择器、分路、比较器和序列运算，均可查看原理并加入函数库。半加器与全加器返回序对（和位，进位），真假和多拍结果直接以中文显示。

一拍延迟的输入格式是 `delay 6_church 1_bool 0_bool 1_bool 1_bool 0_bool 1_bool`：先传数量，再传六个布尔输入，得到 `[假，真，假，真，真，假]`。`delayi` 在数量后多接收一个初始值；`delayat 6_church 4_church …` 读取第4拍输出；`bits` 按输入原顺序生成列表。它们是 λ 程序处理的离散拍序列，不使用真实时间。没有默认开启按需展开，也不修改现有存档。

输入 Lambda 表达式，转换成 John Tromp 图示，再逐步运行 β 归约。支持丘奇数、列表小数、丘奇列表、丘奇布尔及命名自定义编码。无后缀数字使用当前选中的编码，`120_list` 表示数位列表 `[1, 2, 0]`，`0_bool`、`1_bool` 表示假和真。

转换图示保留输入中写出的β归约。例如 `(λtrue.true) (λa.λb.a)` 在第0步仍是原式，点击一次单步才变成 `λa.λb.a`；不会因为参数名叫true、id或其他辅助函数名而提前代入。普通和按需展开模式都遵循此规则，回退与存档恢复保留真实步数。自定义数字编码仍单独遵循其设置的字面量归约步数。

也可在主输入框用 `名称 = 表达式` 定义函数，每行一个，按从上到下的顺序引用，最后可追加要运行的算式。例如：

```text
id = λx.x
double = λn.λf.λx.n f (n f x)
double 3_church
```

点击「保存等号定义」只保存函数，当前图示和归约历史保持原样；点击「转换成图示」会保存定义并准备最后的算式，运行后上例得到6。组合子编译也支持这种写法。定义跨行时用括号包住；函数原始写法保存在编辑器中，重名遵循当前所选方式，编号改名后的引用自动使用实际名称。只有整批准备完成且存储成功才提交函数；输入或恢复草稿不会自动添加定义。已有自定义数字写法若整体匹配数字字面量，仍按原编码解释。

自定义数据编码可填写「输入数字时归约步数」并保存：`0` 不归约，`N` 最多归约 N 步，提前到达正规形即停止；留空沿用归约到正规形。数字后缀和当前编码下的裸数字均使用该步数，每个数字分别计步，不计算外层算式。有限步数不使用缓存或对照表提前替换结果，未完成部分留在图示中继续运行；只有完整正规形才加入对照表。设置和未保存的数字草稿随存档保留，旧版“不归约”设置按0步读取。手动点击「生成并加入」仍可求完整对照项。

从讲解加入解释器后，可直接写 `interpret (表达式)`，也支持嵌套在其他表达式中的直接调用。只传待解释的表达式，转换时准备语法和自由变量环境，运行仍由 λ 解释器和解码器完成；原输入保留用于编辑。已保存的旧版双参数解释器也支持这个调用方式，局部同名绑定和其他同名自定义函数不被替换。`i` 使用函数库中已有定义；没有定义时保持自由变量，不暗中设成恒等函数。

添加函数处提供「重名替换」「重名加数字」「重名跳过」「重名直接使用」四个按钮，手动函数定义与组合子转换共用该选择，并随存档保存；旧存档默认跳过。替换使用新定义覆盖同名函数，加数字从2起选择未占用的名称，例如 nth2、nth3，跳过保留原定义。「重名直接使用」只按名称沿用现有函数，绕过定义相同的判断，继续添加其他函数或生成表达式；重名的辅助依赖也使用现有定义。运行采用这些现有定义，因此结果取决于已有函数的含义。反馈明确显示“沿用现有定义”，不宣称表达式相同。其余模式同名同定义均直接复用；加数字模式也复用已经生成的同定义编号函数，不反复累加。示例与教程使用下述严格原文导入；已转换图示和历史保持原来的函数快照。下文普通添加的重名跳过行为均指默认设置。

三种组合子转换共用「使用特殊化简」开关。取消勾选后，全组合子、SK、BCKW 都只按通用括号抽象及固定基元定义转换，不采用数字、布尔、后继等专用匹配，也不执行转换后的结构化简或 β 归约。普通模式的表达式可能更长。开关随存档保存，与按需展开及归约顺序独立；旧存档保持原先开启特殊化简的行为。

「编译成组合子」在开启特殊化简时可识别23种定义，新增 `m、a、t、v、q、f、r、d、e、j、h、l、o、phi、psi、y、z`。转换栏展开「可用的组合子」可查看每个名称的完整λ定义和中文说明。识别允许绑定变量改名，按实际使用加入完整、自包含的函数定义；例如 `λx.λy.λg.g x y` 转成 `v`，`λf.λg.λh.λx.f (g x) (h x)` 转成 `phi`。`y`、`z` 仅在运行时参与递归，编译不会提前执行它们。SK仍只输出s、k，BCKW仍只输出b、c、k、w；四种重名策略与保存恢复保持可用。

「编译成组合子」由网页的 JavaScript 在表达式外执行。它把输入中的 λ 抽象转换为函数调用，只将实际需要的组合子加入外部函数库；编译器本身不会出现在算式中，也不参与 β 归约。例如平方函数 `λn.(λm.λn.λf.m (n f)) n n` 编译后为 `w b`。线性分支优先使用复合或交换，参数复用时使用 `s`、`w`；保留 β 正规形和自由变量，不执行 η 缩约。复合组合子在转换结果中统一写 b，原有 mul 等数学函数名称不被改写；重名时跳过添加并显示名称，用户函数不被覆盖；无法复用同义基元时保留原算式，等待用户处理重名。

编译只更新输入及所需的函数定义；点击「转换成图示」后再运行。编译结果与函数库都随存档保存，重新载入后可以继续编辑、归约和回退。可用 `node --test tests/combinator-compiler.test.cjs` 和 `node tests/combinator-compiler-browser.cjs` 验证。

开启「使用特殊化简」时，「转换成 SK」使用标准括号抽象并自动化简：`λx.x` 转成 `s k k`，false 转成 `s k`。没有单独的化简按钮或化简轨迹。缺少的 s、k 定义自动加入并保存到函数库，已有正确定义直接复用。同名而定义不同的用户函数保持原样，显示重名并保留原算式，不生成 s2、k2 等新名称。转换后光标位于式子末尾，可继续输入参数。编译仍在表达式外完成，原有「编译成组合子」继续使用较紧凑的多组合子方案。

「转换成 BCKW」使用复合 b、交换 c、丢弃 k 和复制 w 四种组合子，自动补齐所需定义。恒等函数写成 `w k`，s 经复合整理后写成 `b (b w) (b c (b b))`；输出不依赖额外的 s 或 i。BCKW 转换自动应用假值、常量、复合与偏应用规则；例如 `c k x → w k`、`b (w k) (b f g) → b f g`、`c (c (b f)) → b f`。具体规则可在转换栏展开查看；未知自由函数保留必要的 λ 结构。全组合子模式的恒等函数统一写作 i，旧存档里的 id 函数保留原名。变量的绑定和 β 正规形保持原义，重名时跳过添加并显示名称，不追加数字。全组合子、SK、BCKW 三个入口均在表达式外转换，结果和新增定义随存档保存。

示例和原理讲解的「加入函数库」会逐个保存全部命名定义，名称和原始表达式逐字一致；查看、编辑、导出、恢复也保留同一原文，不再把整套辅助定义改写成另一个入口。原文只差空格或绑定变量名也会报告冲突并停止整批导入，只有选择「重名替换」才覆盖；严格示例导入不会用加数字、跳过或直接使用来掩盖不同定义。手动添加与组合子转换仍保留四种重名策略。命名定义仅在转换时准备所需依赖，原始函数体不提前运行；已转换图示和历史保留当时状态，后续编辑仅影响重新转换。此类存档使用v6格式，当前版本仍读取v2至v5旧存档。

现有示例均有独立入口与实际参数表。列表调用可直接写 `tail [1,2,3]`，无需另加列表构造函数；`binomsum n` 在内部固定两个底数为1；`reciprocal 2_church 0.5_decimal` 只传输出位数与要求倒数的小数，分子1已封装。多项式示例中的函数实参使用自包含表达式，导入主入口即可调用。自动测试逐项对照入口调用与完整程序的正规形，并单独验证修改真实操作数后的结果。

列表新增 `nth list n`（第n项）、`indexof list value`（第一次出现的位置）、`last list`（末项）、`init list`（去掉末项）、`take list n`、`drop list n`、`contains list value`、`positions list value`（全部位置）与 `count list value`。序号从1开始；找不到位置返回0，第0项、越界或空表取项也返回0。`positions` 未命中返回空表。按值查找比较丘奇自然数，取项和截取可保留任意λ元素。

「二进制列表」新增七种逐位逻辑门 `notbits`、`andbits`、`orbits`、`xorbits`、`nandbits`、`norbits`、`xnorbits`，以及多位加法器 `addbits`、丘奇数转二进制 `tobits`、二进制转丘奇数 `frombits`。列表高位在前，元素是丘奇数字0、1：`addbits [1,1,1] [1]` 得到 `[1,0,0,0]`，`tobits 13` 得到 `[1,1,0,1]`，`frombits [1,1,0,1]` 得到丘奇数13。不同长度从低位对齐，短表左侧补0；逻辑门保留位宽，加法保留最高进位。`tobits 0` 返回 `[0]`，`frombits []` 返回0。输入框选择丘奇自然数，或给数字加 `_church` 后缀；不使用丘奇布尔真替代丘奇数字1。运算均由普通λ归约执行，含递归的位运算建议选从左到右正规序。新增19个示例均有讲解和独立函数库入口。

BCKW 同样在转换时自动使用适用的短式：false／0 为 `c k`，1 为 `b (w k)`，2 为 `w b`，4 为 `b (w b) (w b)`；更大的自然数按倍增和加一构造。线性复合 `λx.f (g x)` 为 `b f g`，交换 `λx.f x a` 为 `c f a`，复制 `λx.f x x` 为 `w f`。还处理 k 丢弃参数、b/c 的完整应用、常量复合、双重交换和已知函数的安全恒等展开；保留 `λx.f x` 的 λ 层数。规则按真实结构匹配，避免把自由变量或同名异义函数当作已知组合子。编译不会执行输入的无限递归，也不展开 `w w w` 这样的循环。

转换时自动使用常见组合子及丘奇数的紧凑表达和通用结构重写：`k p q → p`、`s k p → s k k`、`s (k p) (k q) → k (p q)`、`k (s k k) → s k`，并对已知闭合组合子的安全展开做缩短。它覆盖 i、k、s、b、c、w、布尔值和任意有限丘奇数。另支持 `mul mul id → mul`，其中 mul 的定义为 B 组合子 `λm.λn.λf.m (n f)`、id 为 `λx.x`；根据实际定义识别，换名后仍适用，同名异义函数不误用此规则。组合子模式的输出名称是 b，SK 输出中对应缩成 `s (k s) k`。化简保持 β 正规形，不把 `λx.f x` 擅自改成自由变量 f；不执行输入中的无限递归，不保证全局最短。普通运行的归约轨迹不因转换而改变。

开启「按需展开函数」并转换成图示后，点击图中的函数名或对应线路可手动展开一层，内部函数继续保留名称。点击选择独立于自动归约的顺序和方向，沿用逐线动画、回退和存档历史；Enter、空格也能操作，20 像素内的轻微移动仍按点击处理。同名绑定变量和普通自由变量不会被误当作函数展开。

开启「按需展开函数」后才显示「数字和列表按函数展开」子开关，默认勾选。取消勾选后，数字和列表直接保留完整表达式，自定义函数仍按需展开；选择随存档保存，关闭再开启父开关时保留。切换后重新转换，原有归约轨迹保留。

勾选子开关后，输入 `2` 可先显示为 n2，输入 `[1,2]` 可先显示为 list1。点击列表先展开外层结构，元素仍可显示为 n1、n2 再分别展开；空表和嵌套列表同样支持。`λx.[x,1]` 这样的列表把外层变量作为参数传递，保留原来的绑定关系。别名只属于当前计算会话，随 v5 存档冻结，不占用用户函数库；重名时自动避让。使用当前式保存函数或记录数据映射时，会还原这些别名，避免留下无法独立调用的名称。

「无限列表 · 按 A 编号生成」接受 `45` 或 `A000045`，另填起始下标和读取项数。内置 A000004（全零）、A000012（全一）、A000027（正整数）、A000040（素数）、A000045（斐波那契）、A000079（二的幂）、A000142（阶乘）、A000217（三角数）、A000290（平方数）、A000578（立方数）、A001477（非负整数）、A005843（非负偶数），各有示例和原理讲解；教程搜索框可以直接输入编号。编号对应 [OEIS A 编号](https://oeis.org/wiki/A-numbers)，算法在本地用真实 λ 归约执行。

生成器 `stream a n` 每次构造 `pair (a n) (stream a (succ n))`，没有长度上限；`take count` 先检查剩余项数，仅消费有限前缀并输出丘奇列表。应使用从左到右正规序，单独要求整个无限流的完整正规形不会终止。界面只载入表达式，不自动转换或运行；数列的下标、项数和元素使用丘奇自然数，参数显式带 `_church`。素数试除、阶乘等较大输入的归约成本会增加。

其他 A000001～A401715 编号可填写接收下标的个人 λ 函数，例如 `λn.λf.λx.f (n f x)` 表示 n+1。规则保存为函数库中的小写编号，例如 `a401715`，可继续编辑或删除；个人规则优先于同编号的内置规则，未核验是否符合 OEIS 原条目。缺少规则时显示未实现，不把有限数据表伪装成无限生成器。数字字段和未完成的规则草稿随当前存档保留；自定义编号的教程按钮打开通用无限列表原理，并明确提示不是该编号的专属证明。

运行区另有独立的「按需展开函数」开关，可配合正规序、应用序以及左右两种方向。默认关闭，转换时先展开全部函数；开启后保留函数名，每次按所选顺序展开一个函数或执行一次 β 归约。函数名仍有定义可展开时不会误报正规形。切换开关后需重新转换，已有计算记录保留到新转换开始。

按需展开的会话保存实际用到的函数定义和展开路径，采用 v5 存档；修改函数库后仍可按原定义重放旧计算、回退及恢复。旧版程序会拒绝 v5，当前程序继续读取 v1–v4。快速求值也会按需读取会话函数定义。新生成的所有示例和讲解统一使用 `λa.λb.λc.…`，不再省略参数之间的点和 λ；用户保存的函数原文保持原样。

v0.3.9 中，函数名展开也使用逐线平滑动画：原线路展开为内部结构，其余线路随布局移动、缩放；回退时反向收回，操作打断时从当前动画进度衔接。

## 直接玩

双击 `dist/lambda-lab.html`，无需安装、联网或启动服务器。

1. 在输入框写表达式，或选一个示例。
2. 用快捷栏插入 λ；字母、空格、点和括号直接键入，点击「转换成图示」。
3. 点击「单步」或「运行」，用「回退」查看上一帧。
4. 在闯关模式中先看任务和提示，自行运行到正规形，再点击「验证答案」。目标答案默认隐藏，可按需点击「查看答案」；切换关卡、刷新或恢复存档后重新隐藏。

闯关可选择「入门五关、函数与绑定、逻辑与数据、自然数进阶、列表小数、高等数学」六个阶段，每阶段5关；原5关记录继续有效。新增小数四则、组合数、阶乘、真正从原系数生成导函数/原函数及定积分。关卡自动选择数值编码，小数除法关预置3位精度；长表达式可以使用「快速运行」，仍保留所有步骤。阶段进度与当前关卡会随存档恢复。

高等数学中，组合数C(4,2)=6，排列数A(4,2)=12。微积分直接接收待处理的丘奇多项式函数，程序内部提取系数：选「生成导函数」，真实β归约把x²+3x的系数表转换成2x+3；选「生成原函数」，程序把2x转换成x²（积分常数取0），输入x则得到1/2x²。结果区能直接显示生成的多项式。

高等数学的多项式求值、生成导函数、求导并求值、生成原函数和定积分程序都内置了纯 λ 编码函数。直接将普通丘奇多项式函数或已保存的函数名放到算式末尾，例如 `(求导程序) (λx.…加法和乘法…)`。输入函数需为自然数系数多项式。

编码程序先计算系数和 `s=f(1)`，取基数 `b=s+1`，再将 `f(b)` 按 b 进制拆位，得到降序系数列表。因为每个系数都小于 b，各位之间没有进位混淆。零多项式单独处理。编码、求导和积分均通过实际 λ 归约完成，较高次数或较大系数可能产生很大的丘奇中间数。

「符号求导并求值」先生成导函数再求值；「定积分」先生成原函数，再计算上下限的差。符号算法位于 `src/polynomial.js`，通过 λ 归约转换系数列表和有理数对。原有系数编码接口继续支持非负有理数。积分端点需为自然数且下限≤上限。

这些结果都由真实β归约得到，可单步、回退、保存和修改输入继续实验。Y递归示例建议使用「正规序」「从左到右」；应用序或从右到左可能持续展开递归。选示例不会更改你的运行设置或函数库。大厅资源 0.3.6 包含这些示例，历史独立 APK 0.3.3 保持原状。

运行区支持直接填写 **1–60000 毫秒/步**，数字越小越快；也可选择「极速」（10 毫秒/步）。运行中修改立即生效，速度随存档保存。

「运行」按设置的每步间隔执行逐步归约，解释器与移位表达式也保持该模式；「快速运行」按短时间片批量执行真实β归约，保留每一个历史AST、每步记录及完整图示，可随时暂停、回退；不预先计算答案、不压缩轨迹，也没有自动停止步数。小数长除法建议使用此按钮及正规序/从左到右。

运行区的「归约顺序」可选择**正规序（外层优先）**或**应用序（内部优先）**，默认正规序。「归约方向」可选择**从左到右**或**从右到左**，默认从左到右，两种顺序均可搭配。两者都归约 λ 函数体内部。单步、自动运行、粉色高亮和下一步说明使用当前选择；运行中可以切换，已有历史保留。

「单步」和「运行」会实际尝试 β 归约，没有归约结果时保持当前式并停止。检查范围包括函数、参数和 λ 函数体：例如 `f ((λx.x) y)` 归约为 `f y`，`λz.(λx.x) z` 归约为 `λz.z`。例如 `(λx.x) ((λy.y) z)`：正规序第一步是 `(λy.y) z`，应用序第一步是 `(λx.x) z`。本项目的应用序选择最内归约项，包含 λ 内部；从右到左时先检查参数，再检查函数，最后归约当前应用。正规序仍优先当前外层项，只有向内部查找时使用方向；图示布局不翻转。

网页支持手动点选归约：点击可归约项顶部的 λ 绑定横条，执行该项的一次替换，可以选择内部项。手机直接点按；键盘聚焦横条后按 Enter 或空格。拖动平移、双指缩放不会归约。自动运行时点选会先暂停；输入已编辑时需重新转换。普通「单步」「运行」采用选择器指定的顺序。

点按时累计位移不超过 **20 CSS 像素**，图示保持不动且可点击归约；超过 20 像素才启动拖动，启动后连续跟随。阈值按屏幕位置计算，不受图示缩放比例影响。

归约顺序、方向偏好和实际轨迹随状态和完整备份保存，刷新、导入后仍能逐步回退。手动、应用序或从右到左的步骤保存实际路径，带路径的存档使用格式 v3；旧档默认正规序、从左到右。当前网页和 v0.3.3 APK 兼容 v1/v2/v3；旧 v0.3.1 APK 不支持手动归约及 v3 存档。v0.3.3 APK 尚无顺序和方向选择器，恢复轨迹后继续执行仍采用正规序从左到右，重新保存会丢失新偏好。

长表达式归约会复用未变化子树的统计和查找结果，避免反复扫描和复制路径；替换、图示布局及文本遍历使用显式栈。图示按变化更新 SVG 元素，暂停或重复尝试时保留原图。全部线条、变量和历史仍完整保留。可用 `node scripts/benchmark-reduction.cjs` 与 `node scripts/benchmark-browser.cjs` 重现性能基准，参数 `ff715b2` 对比优化前版本。

图示在运行中也可以放大：鼠标滚轮或手机双指缩放，拖动平移；「100%」直接显示原尺寸，「适配」查看全图。手动缩放后，后续归约保留比例和观察位置。缩放最高 1600%，观察位置随存档保存。

点击存档栏的「载入默认存档」即可载入集合列表数字示例。每次载入先导出当前完整存档及独立保存点，再清除旧工作区并载入；导出或本地存储操作失败时保留原现场。备份可通过「导入存档」恢复。打开网页或刷新不会自动覆盖用户数据。

载入后草稿是`SET_ADD 1_Set 2_Set`，点击「转换成图示」再点「快速运行」得到`3_Set`。也可尝试`SET_SUCC 0_Set`或`SET_MUL 2_Set 2_Set`。数字写作`3_Set`，或使用已配置的`s3`形式；普通数字按选中的Set编码解释。载入只替换工作区，不自动构建图示或运行算式；修改函数和编码后会自动保存。

## 输入语法

- `λx.x` 或 `\x.x`：恒等函数。
- 无后缀数字按「数字编码」当前选择解释：选丘奇数时`3`是丘奇数；选列表小数时`3`、`-2`、`0.125`是列表小数；选Box时`3`会调用Box转换。
- `3_church`或`3_丘奇数`始终指定丘奇自然数；`3_decimal`、`-2_decimal`、`0.125_decimal`始终指定列表小数，也可以使用`_列表小数`。
- `3_Box`：通过已保存的Box转换函数把丘奇数3转换成自定义数据；可在同一个表达式中混用多个编码。
- 小数加减乘除：从示例选择，输入框会填入完整Lambda程序与数值参数，可直接修改、运行或保存为自己的函数。ADD、DEC_ADD等名称没有内置含义，全部可由你自定义。
- `λx y.x`：`λx.λy.x` 的简写。
- `f x y`：`(f x) y`，应用左结合。
- `f (λx.x)`：作为参数的函数需要括号。
- `xy` 是一个变量名；`x y` 表示应用。
- 变量名以英文字母开头，可含数字、下划线或单引号。
- Ctrl / Command + Enter 转换。

带`_decimal`的输入用字符串逐位编码，支持长整数/有限小数，不经浮点数计算数值。公开数值去掉ID：有理数是 `λk.k 分子 分母`，整数是 `λk.k 正负标记 绝对值`，小数是 `λk.k 正负标记 丘奇数位列表 小数位数`。正负标记true为正、false为负，零统一为正；数位按书写顺序排列，保留整数位的0，例如 `0.125 = λk.k true [0,1,2,5] 3`，1.25用[1,2,5]和位数2表示。纯λ适配函数在运算开始时转换为内部Scott工作表，结束时恢复书写顺序、补足整数位并输出三项记录。旧存档通过布局元数据按原数位顺序读取，保留原AST和计算轨迹；新程序也能接收旧五项输入。旧自制函数若直接拆解旧字段或依赖原来的数位顺序，需要按新结构修改。

除法、平方根、正弦、余弦、正切及三个双曲函数都显式接收输出小数位数：完整程序后第一个参数是 `位数_church`，后面才是小数输入。默认6位，按位数截断，不是四舍五入；近似标记不放进最终数值。改变默认控件后重新选择示例，已有表达式可直接编辑位数参数。工作精度为请求位数加6，级数展开次数随位数增加，圆周率按同一精度计算。加减乘和一位移位保持精确有限结果，不增加位数参数。变量名中的数字不变，例如`f2`仍是变量。

小数二进制左移或右移各接收一个小数，只移一位。需要多次移位时，用丘奇数迭代同一个函数，例如 `3_church (移位函数) (1.25_decimal)`。移位和加法逐位计算，保留有限小数的完整精度。选择丘奇整数后可直接写 `-3`，也可用 `-3_int` 指定编码。

「高等小数」包含取负、绝对值、自然数指数幂、带符号除法、倒数、平方根、三角和双曲函数。三角函数接受 −1000 到 1000 弧度，双曲示例接受 −1 到 1，两者输出近似值。「快速求值」复用 λ 参数的中间结果，直接显示正规形的数值。「单步」或「运行」保留逐步归约轨迹。

「数字编码」列出丘奇数、列表小数及已保存的自定义编码，并显示所选编码的字面量写法。无后缀数字按当前选择解析，带后缀数字优先使用指定编码；切换编码后重新转换即可应用新选择，已运行的历史不被重写。小数示例仍显式加上`_decimal`。当前表达式旁标注输入实际使用的编码，混合输入显示全部名称，保存函数的编码来源也会跟随函数调用。旧v2/v3存档的AST、轨迹和函数保留原义；重新转换草稿时使用新规则。底层`LambdaCore.parseInput`保留旧的纯小数解析接口，新编辑器和函数库使用`LambdaDataEncoding.parse`。

## 自定义数据编码

可自定义每种编码的输入写法：先在「数字编码」中选择类型，再展开「输入形式」，填写含一个`{n}`的模板并保存。例如丘奇数设为`C{n}`后可输入`C3`，设为`{n}c`后可输入`3c`；列表小数可设为`{n}d`并输入`-1.25d`；自定义Box可设为`[{n}]`并输入`[3]`。这些写法在其他编码选中时也会明确指定所属编码。

标准`3_church`、`0.5_decimal`、`3_Box`仍可使用，无后缀数字仍按当前选择解释。模板改变记法，不改变数值域；可恢复默认。模板不能包含空白或λ语法控制符，重复/冲突会提示；普通变量不会被部分替换，`λC3.C3`中的绑定变量仍是变量。输入形式、未保存的编辑草稿随存档保存。准备数字不会自动改变图示，仍需点击「转换成图示」。

展开「自定义数据编码」，名称填写`Box`，转换函数填写`λn.λk.k n`并保存。输入`3_Box`，点击转换时会自动完成数字编码，图示显示`λk.k (丘奇数3)`；输入`3_Box (λx.x)`再运行则可取回丘奇数3。转换函数接收一个丘奇自然数，定义中的普通数字也按丘奇数解释；可引用已保存函数，保存时会把依赖展开。

可保存多个编码并从菜单选取。已保存列表中，每条编码都有「编辑」「删除」按钮；点「编辑」回填原定义，再点「保存修改」更新该条记录。转换函数框下的λ按钮在光标位置插入符号，也可输入反斜杠代替λ。名称支持英文字母和汉字，可含数字、下划线及单引号，内置后缀名称保留。数据转换按普通β归约执行，所有步骤和图示均保留。修改或删除编码不改变已经编译的表达式及函数；新转换使用更新后的定义。编码定义、未保存草稿、当前选择和来源标记随存档导入/导出；「导出存档并清空」也会备份并清除这些内容。自定义转换的数字输入为自然数，负数和小数使用列表小数后缀。

输入单个数字时在后台完成编码归约并缓存，原图示和运行现场保持不变；点击「转换成图示」才显示已编码数据，无需另点运行来展开数字的转换函数。表达式中的数字也会在手动转换时先完成编码。切换编码、刷新或恢复现有计算不会自动重建图示。表达式中的其他计算仍按运行/单步控件执行。编码可取消，重复数字按转换定义缓存；已完成的数字自动加入对照表。新保存的函数中的数字同样先完成编码。

每个编码另有默认收起的「数字 ↔ 表达式对照表」，展开后在固定高度内滚动。表中输入数字会自动生成并加入，也可点「生成并加入」立即生成；生成可取消，不改变主图的计算现场。也可用「使用当前结果」登记已经归约完成的闭合表达式。表中支持编辑对应数字、载入表达式、删除条目；同一数字再次加入会更新原条目。结果与表中表达式α等价时显示如`3_Box`，完整λ表达式仍保留；多个数字对应同一表达式时列出全部匹配。对照表随存档导出导入；修改转换定义会清空旧表，只重命名则保留。

归约默认采用左最外的正规序，可切换为应用序及从右到左，两者都包含 λ 内部。替换自动避免变量捕获。Tromp 图示采用标准横竖连线；自由变量使用带名字的虚线扩展。参见 [John Tromp 原始定义](https://tromp.github.io/cl/diagrams.html)。

主输入和函数定义没有固定字符数量上限，长草稿也可保存和恢复。图示保留全部线路、变量名称与每一步历史。自动运行按实际耗时留出浏览器处理输入的时间，检测重复状态，以及归约后在必须求值的位置再次包含自身计算的递归增长。快速求值同时跟踪尚未完成的函数调用，能停止不断套壳、复制分支和嵌套 λ 的重复递归；顺序执行完的调用会退出检测，不因表达式大或正常复制而停止。检测不依赖线条数量上限，也不压缩图示。任意 Lambda 表达式的终止性不可通用判定。「快速计算保护时长」仅用于快速运行和快速求值，普通运行不创建此计时器，也不检查此窗口。默认1秒：快速运行在窗口内状态仍增长时保护性暂停；快速求值则只要到时仍未完成就暂停，不要求状态增长，也不依赖重复状态。提示明确说明尚未确认终止性，可选择3/10/30秒或主动关闭时长保护。快速运行保留当前式、完整轨迹和回退能力，再次点击快速运行从当前步骤继续；快速求值保留暂停的计算状态，点击「继续求值」继续，点击「取消求值」立即取消。观察时间随存档保存，旧存档默认启用1秒保护。该机制不按线路数或总步数截断，也不把运行较久的有限计算判作无限循环。存档分段重放，可中途取消。存档文件仍保留 2 MiB 格式边界。

## 自定义函数

在「自定义函数」填写名称与定义，例如 `ID = λx.x`，点击「新增函数」。此后在主输入框输入 `ID (λy.y)`，或通过该函数的「插入」按钮调用。也可以用「使用当前式」将当前计算式转存为函数。

名称支持中文、数字开头、下划线和符号（例如 `1号函数`、`_加法`、`+`），没有固定长度上限；纯数字名称在表达式中用反引号包围，直接输入数字仍使用当前数字编码。名称不能含空白、λ、反斜杠、点、括号、逗号和反引号等语法符号。函数数量没有固定上限。每个函数提供「插入」「编辑」「删除」。编辑载入完整名称和定义，支持保存修改、改名、取消；编辑草稿也随存档保存。同名新增会拒绝覆盖，修改已有函数请使用「编辑」。可以组合调用已有函数；λ 绑定的同名变量优先，例如 `λID.ID` 不会调用库中的 ID。定义含自由变量时，展开会自动避免变量捕获。

编辑时显示保存的原始输入，保留函数名调用、数字、空白、换行和 `\` 写法。例如保存 `ID 3` 后编辑仍显示 `ID 3`。原文随自动/手动存档和备份保存。旧函数没有原文记录时显示完整展开式；重新填写原文并保存后也会记住写法。运行仍使用保存时的编译定义，原文未修改地保存或改名不会重新展开依赖；修改原文才重新编译。旧版客户端重新保存可能忽略新增的原文字段。

定义在保存时展开已有函数，因此编辑或删除依赖不会改变已保存的组合函数。已经转换的图示和计算轨迹仍保留当时的定义，再次转换时才采用最新库。

## 状态与进度存档

- 自动保存：刷新或关闭页面后，可恢复原计算帧、归约轨迹、函数库、草稿、当前关卡和已通关进度。
- 保存当前状态：设置一个手动恢复点。之后的自动保存不会覆盖它。
- 恢复已保存状态：回到手动恢复点，保留回退/继续运行能力。恢复时自动运行保持暂停。
- 导出存档：将完整现场下载为 JSON 文件，适合备份或转移到其他设备。
- 导入存档：选择之前导出的文件；验证成功后恢复完整现场。错误文件不改变当前现场。
- 导出存档并清空：先自动备份当前现场及手动保存点，再清空表达式、函数库、运行轨迹、编辑草稿和关卡进度，设置复位。刷新后仍为空；导入备份可恢复当前现场和保存点。只清理本游戏数据。

浏览器只能确认备份下载已发起，请保留下载的 JSON 文件；序列化、导出或存储清理失败时保留当前现场。安卓清空必须等待原生写入成功；v0.3.1 APK 包含此新功能及对应接口。

速度、缩放、展开的归约轨迹和未保存的函数编辑草稿也会保存。兼容旧版 v1 的草稿与关卡进度。文件最多 2 MiB。

无法使用浏览器存储时仍可以计算和导出文件，页面会显示保存失败提示。离线文件与 HTTP 预览的存储空间可能不同，跨入口请使用导出/导入。

## 开发

Node.js 20 或更高，应用与单元测试均不依赖第三方包。

```text
node --test tests/*.test.cjs
node scripts/build.mjs
node scripts/serve.cjs
```

开发预览默认 `http://127.0.0.1:4189/`，可通过 `PORT` 环境变量改端口。源码在 `src/`，过程文档在 `doc/`。

真实浏览器验收：安装 Playwright 与 Chromium 后运行 `node tests/browser.cjs` 与 `node tests/workspace-browser.cjs`。Codex 的捆绑 Node 环境会自动使用捆绑的 Playwright。测试采用临时端口，截图输出到 `tests/artifacts/`。

安卓构建前执行 `npm run build`、`npm run sync:android`、`npm run check:android`，再执行 `npm test`（含安卓结构检查）。`npm run test:android-bridge` 验证完整 JSON/SVG 导出桥接。GitHub Actions 在 Node 20/22 验证测试，并通过 JDK 17、Gradle 8.7、AGP 8.5.2 构建 APK。
