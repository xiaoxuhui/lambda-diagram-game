# Lambda 线路实验室

当前版本：**0.3.0**。许可证：[MIT](LICENSE)。

## 安卓 APK

在 [GitHub Releases](https://github.com/xiaoxuhui/lambda-diagram-game/releases) 下载 `lambda-lab-android-0.3.0-debug.apk` 安装。
支持 Android 7.0 及以上，完整网页内置，无需联网、不申请权限。首次安装可能需要允许此来源安装应用。
APK 使用项目固定 debug 签名；后续升级必须保持相同签名并增加 versionCode，网页与 APK 版本同线。

JSON 存档和 SVG 图示通过原生接口保存：Android 10+ 写入系统下载目录，Android 7–9 写入应用外部文件目录。JSON 导入调用系统文件选择器。
网页、HTTP 预览与 APK 的存储空间互相独立，迁移请使用导出/导入。
打包及验收说明见 [android/README.md](android/README.md) 与 [安卓需求及用例](doc/安卓打包需求与测试用例.md)。

输入 Lambda 表达式，转换成 John Tromp 图示，再逐步运行 β 归约。包含快捷符号栏、自定义函数库、完整状态存档、5 个入门挑战、Church 数与布尔值示例。

## 直接玩

双击 `dist/lambda-lab.html`，无需安装、联网或启动服务器。

1. 在输入框写表达式，或选一个示例。
2. 用快捷栏插入 λ；字母、空格、点和括号直接键入，点击「转换成图示」。
3. 点击「单步」或「运行」，用「回退」查看上一帧。
4. 在闯关模式中运行到正规形，点击「验证答案」。

运行区支持直接填写 **1–60000 毫秒/步**，数字越小越快；也可选择「极速」（10 毫秒/步）。运行中修改立即生效，速度随存档保存。

图示在运行中也可以放大：鼠标滚轮或手机双指缩放，拖动平移；「100%」直接显示原尺寸，「适配」查看全图。手动缩放后，后续归约保留比例和观察位置。缩放最高 1600%，观察位置随存档保存。

## 输入语法

- `λx.x` 或 `\x.x`：恒等函数。
- `0`、`1`、`2`、`3`：自动展开为对应丘奇数。例如 `3` 等于 `λf.λx.f (f (f x))`，可写 `ADD 2 3` 调用自定义加法函数。
- `λx y.x`：`λx.λy.x` 的简写。
- `f x y`：`(f x) y`，应用左结合。
- `f (λx.x)`：作为参数的函数需要括号。
- `xy` 是一个变量名；`x y` 表示应用。
- 变量名以英文字母开头，可含数字、下划线或单引号。
- Ctrl / Command + Enter 转换。

数字支持可精确表示的非负整数，自动展开为完整丘奇数。负数、小数和超出可精确表示范围的数字会提示错误；变量名中的数字不变，例如 `f2` 仍是变量。

归约采用左最外的正常序，包含 λ 内部。替换自动避免变量捕获。Tromp 图示采用标准横竖连线；自由变量使用带名字的虚线扩展。参见 [John Tromp 原始定义](https://tromp.github.io/cl/diagrams.html)。

主输入限 1500 字符。图示没有固定节点、线路或展开深度数量上限，运行没有固定步数或重复状态自动暂停；到达正规形时结束，运行中可手动暂停。图示保留全部线路、变量名称与每一步历史。

## 自定义函数

在「自定义函数」填写名称与定义，例如 `ID = λx.x`，点击「新增函数」。此后在主输入框输入 `ID (λy.y)`，或通过该函数的「插入」按钮调用。也可以用「使用当前式」将当前计算式转存为函数。

名称以英文字母开头，最多 32 字符；函数数量没有固定上限。每个函数提供「插入」「编辑」「删除」。编辑载入完整名称和定义，支持保存修改、改名、取消；编辑草稿也随存档保存。同名新增会拒绝覆盖，修改已有函数请使用「编辑」。可以组合调用已有函数；λ 绑定的同名变量优先，例如 `λID.ID` 不会调用库中的 ID。定义含自由变量时，展开会自动避免变量捕获。

定义在保存时展开已有函数，因此编辑或删除依赖不会改变已保存的组合函数。已经转换的图示和计算轨迹仍保留当时的定义，再次转换时才采用最新库。

## 状态与进度存档

- 自动保存：刷新或关闭页面后，可恢复原计算帧、归约轨迹、函数库、草稿、当前关卡和已通关进度。
- 保存当前状态：设置一个手动恢复点。之后的自动保存不会覆盖它。
- 恢复已保存状态：回到手动恢复点，保留回退/继续运行能力。恢复时自动运行保持暂停。
- 导出存档：将完整现场下载为 JSON 文件，适合备份或转移到其他设备。
- 导入存档：选择之前导出的文件；验证成功后恢复完整现场。错误文件不改变当前现场。
- 导出存档并清空：先自动备份当前现场及手动保存点，再清空表达式、函数库、运行轨迹、编辑草稿和关卡进度，设置复位。刷新后仍为空；导入备份可恢复当前现场和保存点。只清理本游戏数据。

浏览器只能确认备份下载已发起，请保留下载的 JSON 文件；序列化、导出或存储清理失败时保留当前现场。安卓清空必须等待原生写入成功；已发布的 v0.3.0 APK 尚不包含此新功能，更新后的原生接口将随下一次 APK 发布提供。

速度、缩放、展开的归约轨迹和未保存的函数编辑草稿也会保存。兼容旧版 v1 的草稿与关卡进度。文件最多 2 MiB。

无法使用浏览器存储时仍可以计算和导出文件，页面会显示保存失败提示。离线文件与 HTTP 预览的存储空间可能不同，跨入口请使用导出/导入。

## 开发

Node.js 20 或更高，应用与单元测试均不依赖第三方包。

```text
node --test tests/*.test.cjs
node scripts/build.mjs
node scripts/serve.cjs
```

开发预览默认 `http://127.0.0.1:4189/`，可通过 `PORT` 环境变量改端口。源码在 `src/`，过程文档在 `doc/`。

真实浏览器验收：安装 Playwright 与 Chromium 后运行 `node tests/browser.cjs` 与 `node tests/workspace-browser.cjs`。Codex 的捆绑 Node 环境会自动使用捆绑的 Playwright。测试采用临时端口，截图输出到 `tests/artifacts/`。

安卓构建前执行 `npm run build`、`npm run sync:android`、`npm run check:android`，再执行 `npm test`（含安卓结构检查）。`npm run test:android-bridge` 验证完整 JSON/SVG 导出桥接。GitHub Actions 在 Node 20/22 验证测试，并通过 JDK 17、Gradle 8.7、AGP 8.5.2 构建 APK。
