x 是变量；λx.x 是函数；f x 把 x 交给 f。(λx.x) y → y 是一次 β 归约。

怎么写、怎么看

用快捷栏插入 λ；也可用 \。λx y.x 等同 λx.λy.x。变量之间用空格：xy 是一个名字。λ 的作用域延伸到右侧，作为参数时需加括号。

同色竖线连接绑定横线；应用横线连接子式最左变量。高亮的粗线标记下一步归约，自由变量以虚线显示。可选择正规序（外层优先）或应用序（内部优先），都包含函数内部归约。John Tromp 原始说明 ↗

    BCKW 自动化简规则

    开启「使用特殊化简」后，转换成 BCKW 时应用；关闭时只做通用转换。这里 i 表示 w k，p、q、r、x 是任意表达式；按实际函数定义识别组合子，用户的同名函数不会被当成这些组合子。

    • k p q → p
    • b p q x → p (q x)
    • c p q x → p x q
    • w k x → x
    • c k x → w k：假值接收一个参数后得到恒等函数。
    • k (w k) → c k；w (c k) → w k
    • b (k p) q → k p；b p (k q) → k (p q)
    • c (k p) q → k (p q)；c b (w k) → b (w k)
    • b (b p q) r → b p (b q r)：整理连续复合。
    • b i p → p、b p i → p、w (k p) → p：仅在能确认 p 至少接收一个参数时使用，包含尚未传满参数的组合子。
    • c (c p) → p：仅在能确认 p 至少接收两个参数时使用。
    • h = c (b c (b (b b) (c b i))) i 可整理为 b (b i)，即 λf.λx.λy.f x y；b succ h → succ 仅按丘奇后继的实际定义匹配。在 BCKW 中后继写成 b w (c (b b b))。

    未知自由变量保留必要的 λ 结构；复制规则只处理能安全展开的结构，w w w 留给运行按钮计算。规则不保证结果最短。
