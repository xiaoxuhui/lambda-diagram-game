# 正规序与应用序

2026-10-12。按用户“加正规序和应用序”理解，在运行区选择两种归约顺序，默认正规序。

- 正规序：最左外层 β 项优先，保持原行为。
- 应用序：最左内部 β 项优先，先函数子项、再参数、再当前应用。两种都进入 λ 函数体，不将应用序简化为弱求值。
- 单步、运行、粉色高亮和下一步解释统一使用当前选择。运行中切换重新安排定时器，之后采用新选择，已有历史不变。
- 选择随存档保存。应用序每步记录实际路径，混合顺序、手动点选、回退、刷新和导入精确恢复。旧档默认正规序，清空复位正规序。

U01 `(λx.x) ((λy.y) z)` 的第一步两序不同、最后都为z；U02 正规序丢弃未用Ω参数、应用序继续归约Ω；U03 应用序先函数体内部再参数；U04 两序高亮和解释正确；U05 运行中切换后续步骤、不重置历史；U06 混合顺序存档/导入/回退；U07 旧档、清空及非法选项验证；U08 手机和离线入口可用，手动点选仍能指定项。
