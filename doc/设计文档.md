# Lambda 线路实验室：设计文档

版本：0.1.0；日期：2026-10-09；状态：已实现并验证；策略：领域核心 → 图示 → 游戏界面 → 真实浏览器验证。

## 设计目标

1. 输入简单、归约准确、图示与当前式同步。
2. 不依赖网络运行；可双击离线 HTML。
3. 领域逻辑独立测试，错误与资源上限显式呈现。

## 模块

- src/core.js：词法、递归下降解析、AST、格式化、自由变量、α 等价、防捕获替换、正常序单步归约、Church 数识别。
- src/diagram.js：纯布局函数与 SVG 输出。叶子按左到右排列；抽象位于子树顶部；应用连接子项最左变量且位于两子项底部之下；变量竖线从其最近绑定 λ 伸至使用位置。颜色仅辅助阅读，几何关系保持标准。
- src/presets.js：示例与关卡定义。
- src/app.js + src/style.css + index.html：编辑器、快捷栏、运行状态机、游戏进度、SVG 视图。
- scripts/build.mjs：将源 CSS 与 JavaScript 内联进 dist/lambda-lab.html，支持 file:// 离线运行。
- tests/：Node 内置测试与 Playwright 浏览器交互。

## 领域决策

使用明确命名的不可变 AST：Var(name)、Abs(param, body)、App(fn,arg)。防捕获替换遇到与实参自由变量冲突的绑定名时使用新名字。正常序每步只改写一个最左最外 redex。α 等价用绑定栈对应，不能把不同自由变量当作相等。

范围只需要一个小型、有界的无类型解释器；现有库往往附带其他文法/运行策略且无法保证离线单文件交付，本轮采用独立核心，并用标准归约例、防捕获反例与 α 等价测试验证。图示按作者原始定义实现，非普通 AST 树。

## 状态

编辑源式与运行式分离。转换成功后初始化历史；每步加入快照；回退弹出一个快照；重置回到转换时的起点；用户编辑后计时器停止并禁用归约操作，直到重新转换。自动运行以单次 setTimeout 调度，每轮预算 200 步，用户暂停可立即生效。循环检测只在运行中提示并停止，不宣称一般性的停机判定。

## 上限与存储

1500 输入字符、300 深度、4000 节点、展开变量名文本 30000 字符；历史最多 201 帧。归约构建中就计量节点，避免指数替换后才判断。存储版本 lambda-lab-v1，保存草稿、模式、当前关卡与通关编号，try/catch 隔离存储失败。

## 验证策略

核心 Node 测试涵盖 U01–U06；图示结构测试涵盖 U07；Playwright 驱动真实 Chromium 检查 U08–U12，包括桌面与移动视口、控制台错误、离线文件与 SVG 下载。构建后检查生成产物，记录实际命令与数量。

## 0.2.0 扩展设计

- src/library.js：纯函数库操作，Map 查找，定义保存展开后的 AST。对源式中的自由函数名称先替换为不会冲突的临时变量，再以 core.substitute 替换为定义，实现同时、卫生的展开；不再展开插入定义内部的自由变量。λ 中绑定的同名变量不展开。
- src/snapshot.js：v2 编解码、AST 校验、v1 迁移和确定性重放。仅保存起始 AST 与步数，恢复时重放最多 200 步重建轨迹；不受源式 1500 字符限制，仍受 AST 原有节点、深度和文本预算限制。
- src/workspace-tools.js：函数库与存档界面，隔离 DOM/存储/下载。app.js 通过明确的捕获/应用状态接口接入。
- 自动状态键 lambda-lab-v2；手动恢复点键 lambda-lab-checkpoint-v2；原 lambda-lab-v1 只在没有 v2 时读取。导入先验证再应用，不把文件内容作为代码执行。
- 存档最大 2 MiB；草稿最多 10000 字符（允许保留超限输入的错误现场）；函数名最多 32 字符、最多 32 个；库总节点/名字预算限制防止大库耗尽存储。
- 保存自动运行现场时保留当前帧，但不保存运行计时器，恢复永远暂停。
