# 点击横条归约

日期：2026-10-11；状态：VERIFIED。用户明确操作为点击，不是拖动。证据见点击归约测试报告。

可归约应用 `(λx.M) N` 的 λ 绑定横条提供点击/触摸目标。点击任意这样的横条，只归约所选项一次；自动单步与运行仍采用左最外正常序。嵌套函数、参数和 λ 函数体均可选。非归约横条不触发。拖动、双指缩放、取消手势不归约。自动运行时点击会先暂停再执行所选一步；输入已编辑但未转换时不能操作旧图。

| 用例 | 验收 |
| --- | --- |
| U01 | 鼠标点击顶部 λ 横条只归约一次，回退/重置正确。 |
| U02 | 有多个可归约项时能选择非默认项，嵌套项与防变量捕获正确。 |
| U03 | 点击普通横条不归约；编辑未转换和正规形无可点击目标。 |
| U04 | 从横条拖动、双指缩放、pointercancel 不归约。 |
| U05 | 手机真实触摸点按可归约，放大平移后目标仍准确。 |
| U06 | 运行中点击先暂停；手势期间图已变化则忽略旧目标。 |
| U07 | 保存、刷新、导出/导入准确恢复手动顺序、全历史和回退；兼容旧档。 |
| U08 | 键盘 Enter/空格可触发；离线 HTML 可用，无浏览器异常，原图线条完整。 |
