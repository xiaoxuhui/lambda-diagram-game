# 实际尝试归约测试报告

## 诊断与实现

原引擎 findRedex 已检查 fn、arg、body，内部归约并未缺失。本次依照用户要求调整执行流程：有效表达式的运行与单步不再因预检查而禁用；真正 step 返回 null 才终止运行。findRedex 仍用于高亮、提示及是否需要即时尝试的调度建议，不能单独终止执行。

自动运行在最后一步后实际确认不可继续，立即停止，不为一次空操作额外等待速度间隔。对已在正规形的表达式点击运行，也立即实际尝试；未转换或非法输入仍不可执行。正常序、β 规则及存档结构不变。

## 新增交互范围

1. λz.(λx.x) z 单步到 λz.z。
2. f ((λx.x) ((λy.y) z)) 运行到 f z，实际尝试记录 `[true,true,false]`。
3. ((λx.x) f) ((λy.y) z) 先归约函数子式，再归约参数。
4. λa.λb.f ((λx.x) b) 自动深入多层函数体。
5. (λx.y) Ω 保持外层优先，一步得到 y，不先展开未使用的发散参数。
6. λx.x 单步与运行都实际尝试，失败时没有新增历史和步数。

9. 最后一次替换后立即确认无下一步，不增加空等待。
