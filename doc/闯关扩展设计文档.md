# 闯关扩展设计文档

日期：2026-10-25。状态：实施中。策略：沿用现有纯Lambda引擎，扩充数据和挑战界面。

1. `presets.js`保留原5关并追加25关，输出6个阶段元数据。目标分为Lambda式、小数、多项式和有理数。
2. 新增`challenges.js`负责起始式编译和目标判定。四则与微积分仍由现有纯Lambda程序逐步归约；目标比较不代替求值。小数比较须拒绝近似和错误值。
3. 页面阶段选择器与当前阶段5个关卡按钮结合，阶段选择恢复该阶段第1关。当前关卡索引可推导阶段，无需新存档字段。
4. 选择关卡自动设置编码；小数除法关精度为3。完成后显示该关、阶段或全部通关提示，下一关自然进入后一阶段。
5. v2/v3存档以当前关卡目录校验完成ID和索引；v1迁移保留原格式的前5关约束。保持版本号和其他存档字段不变。
6. 单元测试实际遍历全部30关，另测错误目标和存档边界；真实浏览器覆盖桌面/手机阶段选择、通关、刷新、离线文件和旧记录。
