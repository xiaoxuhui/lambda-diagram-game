# 默认存档：集合列表数字

- **Status**: PENDING
- **Approved**: 2026-11-04 用户要求默认存档，每次载入前导出原存档并清空，内含自定义函数/编码及集合列表算式
- **Type**: feature

## 需求与设计

新增「载入默认存档」按钮。每次点击先构造并验证预置存档，再导出当前完整备份（包括独立保存点），成功发起备份/原生确认后完整替换当前工作区。旧函数、编码、输入形式、草稿、计算轨迹、关卡进度与保存点均清除，默认函数和编码自动保存。导出失败或本地存储写入失败时保持旧工作区，沿用原清空功能的事务与回滚机制。不在打开网页或刷新时自动覆盖用户数据。

预置集合列表数字Set：0为空Church列表[]；S(n)=APPEND n [n]，即在当前列表末尾追加该列表自身。1=[[]]，2=[[],[[]]]，对应有限集合式数字。内置列表拼接、构造、取首尾、判空、长度；集合零、后继、加法、乘法、丘奇数互转函数。所有算式通过λ归约计算，数字转换函数为n次迭代集合后继，默认准备0至5的识别表（不限制后续输入或添加其他数字）。

载入后的草稿为`SET_ADD 1_Set 2_Set`，不自动转换图示、不自动运行。选择Set编码，用户点击转换和快速运行即可得到3_Set；函数原始定义可以编辑，编码与输入形式继续可改。
