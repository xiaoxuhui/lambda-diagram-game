# 闯关提示需求与设计

日期：2026-10-31。状态：实施中。

用户要求不要默认给出答案，改为提供提示。

- 默认显示关卡任务与解题提示，完整答案只在主动点击「查看答案」后显示。
- 切换关卡/阶段、重新进入闯关、刷新或导入存档后，答案重新隐藏；答案展开状态不写入存档。
- 说明及默认提示中删除直接写出的最终结果，保留输入、所求操作和方法引导。数学起始式、目标判定与通关记录不变。
- 可收起/显示提示，也可查看/收起答案；按钮提供aria-expanded与aria-controls。默认答案区hidden且清空文本，不向屏幕阅读器提前读出答案。
- 自由实验的实际计算结果正常显示；玩家运行后得到自己的结果不受影响。

实现：index.html为目标区增加id与hidden，加入答案开关；app.js集中控制答案显示，在切关及恢复存档时复位，renderLevels只在主动展开时填充目标文本。presets.js逐关修改泄露结果的说明和提示，不改start/target。沿用原hintOpen存档字段，选择新关卡时默认展开提示，刷新尊重已保存的提示开关。

验收：全部30关选择时答案不可见、提示可见；指定数值/微积分关说明无完整答案；展开/收起、跨关、刷新、存档恢复均不泄露答案；验证逻辑仍通过；桌面/手机无溢出；离线HTML同步更新。
