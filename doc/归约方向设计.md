# 归约方向设计

core 增加 DIRECTIONS=['left','right']，findRedex 第四参数 direction，step 第三参数，normalize 第四参数；均默认 left，保留原 API。复用缓存与迭代查找。正规序先返回当前 β 项，子项查找根据方向选择 fn/arg 或 arg/fn；应用序子项都无 redex 时返回当前 β 项。

app state.direction 独立于 strategy。所有自动查找传入两者，手动 stepAt 不变。新增 select 和统一偏好变更处理，运行时取消旧计时器、重新安排下一步。

view.direction 可选，严格校验；旧档缺字段取 left。右方向或应用序步骤记录实际 session.paths；null 永远仍代表历史正规序从左到右，避免偏好变化改变旧轨迹。沿用 v3，不改变表达式和图示布局。
