# 列表小数测试报告

2026-10-24。默认整数、负数、有限小数改为符号+十进制数字列表+小数位置编码，附近似标记；数字低位在前以支持进借位。每一位用0到9的小型Church数编码，整个数不展开成一元Church自然数。默认四则示例共4个，总示例38、分类7。

## 算法与范围

`src/decimal.js`保存实际Lambda逐位对齐/进借位、竖式乘法与长除法程序。`DEC_ADD/SUB/MUL/DIV`及未被自定义覆盖的简名展开为闭合AST，经原引擎真实β归约。JavaScript只做字符串编码/格式化，不计算四则答案。数值不转成浮点数，长整数9007199254740993123456789.123456789往返保持。

除法默认6位，按用户选择截断；有余数标≈，余数为0显示精确值，除0得到明确错误。可改精度，不宣称已经实现任意无限小数流或三角函数。旧多项式/丘奇示例仍为兼容编码，不冒称它们的内部算法已全部迁移到小数。

快速运行按8ms时间片执行原始β步骤，全部AST和历史记录保留，图示保留完整线路，没有隐藏计算、压缩存档或固定步数自动暂停。逐步运行仍按原毫秒间隔，快速运行可暂停/回退。长除法规范化每一位后再处理下一位，避免惰性替换重复展开前面余数；该过程也是Lambda列表操作，不是宿主数字计算。
