# 自定义数据编码

- **Status**: COMPLETE
- **Approved**: 2026-11-02 用户要求自定义转换函数；最新修正为无后缀使用当前选中编码，带后缀明确指定编码（含丘奇数）
- **Type**: feature

## 需求与设计

支持多个命名编码，每个提供一个闭合λ函数，将丘奇自然数转成用户数据。`3_MyData` 在解析时生成「转换函数 丘奇数3」，转换经过普通β归约，不在JavaScript预先求值。转换函数定义中的普通数字也按丘奇数解析，可引用已存函数（保存时展开），不允许未定义自由变量。

无后缀数字使用当前选中的编码；带后缀明确指定编码，例如 `0.1_decimal`、`3_church`、`3_丘奇数`、`3_MyData`，优先于当前选择。选择菜单改变后重新转换，按新选择解释无后缀数字，已编译历史不重写。转换函数定义本身默认按丘奇数解析（也允许显式后缀），主编辑器和自定义函数定义按当前选中编码解析。原小数示例显式加decimal后缀，旧存档的已编译AST保持原义。

提供名称、转换函数、保存/编辑及删除；不新增快捷输入符号。编码注册表、草稿、所选编码和当前表达式的来源编码信息随存档保存、恢复、导出和清空。删除或修改编码不会改动已编译的表达式和函数。

当前表达式旁显示其数字来源编码，混合表达式列出全部编码；依据原输入实际字面量记录，不根据任意λ结构猜测用户数据，也不虚构解码器。自定义转换输入仅为自然数；负数/小数需使用列表小数编码。

- **Objective**：每个自定义编码保存一张数字与正规形表达式对照表，运行结果按α等价反查并显示数字及编码名称。

- **Files**：src/data-encoding.js、src/data-encoding-editor.js、src/encoding-table.js、src/snapshot.js、src/app.js、src/style.css、scripts/build.mjs、index.html、tests、README.md。
- **Design**：输入一个自然数，点击生成并加入，以现有β引擎分批归约转换函数，不设固定归约步数上限，可取消；也可把当前已归约的表达式登记到该数字。表内可编辑数字、载入表达式和删除。多个数字映射到相同正规形时显示全部匹配，不冒认唯一答案。修改转换定义会清空旧表；仅改名保留表。主图和完整归约轨迹不因识别而改变。
