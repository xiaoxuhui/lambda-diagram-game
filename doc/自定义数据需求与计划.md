# 自定义数据编码

- **Status**: VERIFIED
- **Approved**: 2026-11-02 用户要求自定义转换函数；确认数字使用「数字_编码名称」，无后缀默认丘奇数
- **Type**: feature

## 需求与设计

支持多个命名编码，每个提供一个闭合λ函数，将丘奇自然数转成用户数据。`3_MyData` 在解析时生成「转换函数 丘奇数3」，转换经过普通β归约，不在JavaScript预先求值。转换函数定义中的普通数字也按丘奇数解析，可引用已存函数（保存时展开），不允许未定义自由变量。

无后缀数字统一为丘奇自然数；列表小数用 `0.1_decimal`，显式丘奇数可用 `3_church`。内置后缀也支持「丘奇数」「列表小数」。选择菜单显示内置编码与已保存的自定义编码，给出对应字面量写法；不会隐式改写输入。原小数示例载入时显式加decimal后缀，旧存档的已编译AST保持原义。

提供名称、转换函数、保存/编辑及删除；不新增快捷输入符号。编码注册表、草稿、所选编码和当前表达式的来源编码信息随存档保存、恢复、导出和清空。删除或修改编码不会改动已编译的表达式和函数。

当前表达式旁显示其数字来源编码，混合表达式列出全部编码；依据原输入实际字面量记录，不根据任意λ结构猜测用户数据，也不虚构解码器。自定义转换输入仅为自然数；负数/小数需使用列表小数编码。
