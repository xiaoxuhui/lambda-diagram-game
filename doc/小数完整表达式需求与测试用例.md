# 小数完整表达式需求与测试用例

日期：2026-10-30。状态：实施中。

用户要求删除内置小数运算名称，改为直接输入一大串Lambda表达式；长表达式写不下时去掉长度限制。

- U01：ADD、SUB、MUL、DIV、DEC_ADD、DEC_SUB、DEC_MUL、DEC_DIV不再自动展开，DECADD同样是普通名字；仍可保存、编辑、调用同名自定义函数。
- U02：四则示例与小数关卡填入完整、闭合的Lambda程序，外加数值参数；加减乘除仍进行真实β归约，不用宿主语言预算答案。内部局部λ绑定不算外部命名函数。
- U03：主输入及函数定义默认不再限制1500字符，存档草稿不再限制10000字符；计数器只显示实际字数，长表达式可编辑、保存、刷新恢复。
- U04：除法精度在生成完整表达式时写入程序。选择小数除法示例使用当前精度，关卡使用本关预置精度；之后修改精度控件需重新选择示例，不暗改用户已有文本。
- U05：旧存档的AST、完整历史和已编译函数继续使用原含义；旧草稿再次转换时按新规则解析名字，不再暗中调用内置运算。
- U06：桌面与手机实测长式运行、重载、自定义DEC_ADD及原有30关；离线HTML重新构建并同步安卓网页资源。本轮不发布APK或远程版本。

函数名格式和32字符名称上限、存档2MiB文件上限属于其他边界，本轮不改变；不限制表达式正文长度。
