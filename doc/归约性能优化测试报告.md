# 长表达式归约性能优化测试报告

日期：2026-10-09。基线 ff715b2；引擎优化 b610ede；界面与完整图示优化 9ed432e；关闭线条过渡 5313e19。

## 结论与实现

优化重复扫描、路径复制、自由变量判断、相等判断、长链调用栈和整张 SVG 重建。内部 AST 节点不可变，WeakMap 保存统计及查找信息；外部可变 AST 不使用跨调用缓存。每个逻辑出现位置仍计数、输出和绘制，JSON、SVG、表达式及历史没有压缩、截断或数量限制。

替换只重建改变的分支；查找、替换、格式化、统计、自由变量与图示布局使用显式栈。图示路径完整保留，只在请求路径数组时构造，避免为每一条线反复复制所有祖先路径。应用界面对改变的 SVG 属性、增加/删除的线条和标签进行更新；未变化帧不重建 SVG 或历史节点。

实际查看桌面与手机截图，发现旧 CSS 的 stroke 过渡在节点复用后会暂时显示旧绑定颜色，并可触发大批线条动画。关闭该过渡，保持新颜色即时准确显示；新浏览器用例明确检查 transitionDuration 为 0s。
