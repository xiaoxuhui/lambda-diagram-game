# 函数原文编辑

2026-10-12，用户要求编辑函数时显示原来自己输入的形式，保留函数名调用、数字、空白、换行和反斜线写法。

新增/修改后同时保存 source 原文和 term 已编译定义。编辑显示 source；旧函数缺少 source 时回退到完整展开式，不猜测原输入。原文随自动存档、手动保存、导入导出和清空备份保存。依赖被编辑或删除后，无修改地保存/改名应保持原编译定义；实际修改源文本才重新编译。

U01 原文字符完全一致；U02 数字/函数别名编辑不展开；U03 刷新/恢复/导入原文不丢；U04 依赖修改/删除后原文不变的保存不改变运行定义；U05 旧档兼容且完整展开式仍可编辑；U06 非字符串 source 导入拒绝；U07 真实浏览器和离线入口可用。
