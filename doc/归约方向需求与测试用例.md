# 归约方向需求与测试用例

2026-10-13，用户要求再加入从右到左。保留正规序/应用序，增加独立方向选择器，默认从左到右。

- 正规序先当前外层项；无法归约当前层时，从所选方向扫描子项。
- 应用序先内部项；从右到左时先参数，再函数，最后当前应用。两种方向都检查 λ 函数体。
- 高亮、解释、单步与运行统一采用选择。运行中切换保留历史且下一步立即使用新方向。
- 方向和实际路径保存，回退、刷新、保存点和导入完整恢复。旧档默认从左到右，清空复位。
- 手动点选仍归约指定项。图示不翻转、不压缩，不增加数量或步数限制。本次不发布新 APK。

U01 两个并列可归约项在两种策略下先右后左；U02 正规序外层优先不变，右应用序先参数后函数体；U03 λ 内部、防变量捕获、深层迭代；U04 混合方向路径重放；U05 旧档/非法方向；U06 高亮/解释/单步统一；U07 运行中切换；U08 刷新/保存点/备份导入/回退/清空；U09 手机与离线、手动点选。
