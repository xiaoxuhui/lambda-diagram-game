## 已验证项目

1. 许可证：LICENSE 为 MIT，版权人 xiaoxuhui、年份 2026；package.json license 一致。静态网页与 APK 项目不发布 npm 包，private:true 保留。
2. 项目清单：版本 0.3.0，repository、homepage、bugs、engines 明确。APK versionName 同线，首包 versionCode 1。
3. 本地测试：`node --test tests/*.test.cjs tests/android-shell.test.mjs` 共 120 项通过，无跳过。11 项 Android 结构测试确认身份、离线资源、图标、固定签名和系统栏配置。
4. 浏览器：本地普通玩法 28 项、工作区 23 项、原生桥模拟 5 项通过；云端 Web tests 还执行速度、缩放、编辑及数字回归，Node 20/22 矩阵通过。模拟桥验证不等于真实 WebView 或真机测试。
5. CI：网页工作流包含构建、资源同步、单元测试与真实 Chromium 交互；APK 工作流包含真正 Kotlin/Android 构建、资源字节检查、证书字节比对、apksigner 验证及最终 Manifest 身份/无权限检查。
6. CHANGELOG：存在带日期的 0.3.0 条目及之前网页版本记录。
7. 文档：README 覆盖运行、安装、用法、版本、存档、测试、许可证及仓库反馈；4 个本地 Markdown 链接已实际检查，无失效链接；旧数量限制说明已修正。
8. 仓库卫生：扫描源码及文档未发现私钥文本或 GitHub token；没有 TODO/FIXME 占位；console.log 只在服务、构建与同步工具。固定 debug.keystore 为本项目专用的公开开发签名，并非私密生产凭据，按打包技能明确入库。
9. 图标：程序化可复现；已实际查看 512px 图标。桌面/手机布局已有真实浏览器截图和检查。
