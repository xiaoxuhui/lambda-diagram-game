# 默认列表小数与四则运算

用户确认用符号、数字列表、小数位置表示数值，并要求改进加减乘除、把默认数据从丘奇数改为此编码。默认编辑器采用列表小数，支持负数、精确有限小数和整数；旧丘奇示例/存档保持显式兼容模式，不改变已保存AST及轨迹的数学含义。

表示为有标记的Lambda元组：符号、低位在前的Scott数字列表、小数位数、是否近似。每个十进制数字仍由小型Church数表示，但整个数不编码成一元自然数。零规范为正零。输入与格式化用字符串，计算必须在Lambda程序中逐位完成，不用JavaScript预算答案。

加减按小数位对齐并逐位进/借位，乘法按十进制位做竖式；除法用长除法，精度控件明确指定截断位数（默认6），余数未清零时结果标≈。除以零报错状态，不显示0或无限值为正确答案。精度不意味着完整实数支持，三角函数不在本轮范围。

新增默认编码选择与小数四则入口；数字、负号和小数点直接输入。内置DEC_ADD/DEC_SUB/DEC_MUL/DEC_DIV及简名在未被自定义函数覆盖时展开为真实Lambda程序。函数库新定义沿当前模式解析，旧定义未改原文时复用其AST。模式与精度随存档保存；旧存档缺字段时使用丘奇兼容模式，空白新游戏默认小数。

验收覆盖0.1+0.2=0.3、负数抵消/借位、多位进位、0.2×0.3=0.06、1÷8=0.125、1÷3标近似、除零、大整数/长小数的编码往返；默认输入/函数库/保存导入/旧轨迹及桌面手机实测。
