# 导出存档并清空：需求与设计

日期：2026-10-09。用户要求新增按钮，删除所有内容并自动导出存档。

## 需求与验收

- U01 点击「导出存档并清空」，先生成完整 JSON 备份，然后清空表达式、图示、归约历史、函数库、函数编辑草稿、通关进度及手动保存点；速度、缩放、模式和面板复位。
- U02 备份保留清空前的当前状态及已有手动保存点，导入可恢复；格式保留 version 2，已有普通存档继续兼容。
- U03 序列化或导出失败时不清空，显示原因。浏览器下载只能确认已发起，无法确认用户最终保存；安卓必须得到原生写入成功结果后才清空。
- U04 清空时停止自动运行，取消旧的自动保存定时器；重新加载仍为空，不恢复旧版存储或保存点。
- U05 只处理本游戏的三个存储键，不删除其他网站或工具的数据。存储删除失败时保留当前现场并报告。
- U06 重复点击、空工作区、桌面和手机触摸均可用，页面无异常；离线单文件和安卓桥模拟覆盖相同行为。

## 设计

沿用顶部存档操作栏，增加独立醒目按钮和清空范围说明。用户已明确要求清空，按钮直接执行，不额外弹出确认。

LambdaSnapshot 提供包含可选 checkpoint 的完整备份；旧普通存档不改变保存点行为。LambdaWorkspace 负责先导出、删除本游戏存储、清空库及草稿，再通过现有 apply 接口恢复空快照并持久化。空快照 hasSession 为 true，避免自动载入示例。额外保存点仅在完整备份导入时恢复。

LambdaDownload 增加备份接口。普通浏览器使用现有下载机制；Android 增加同步返回成功的 saveFileConfirmed 接口（运行于 WebView JS 桥线程），保留原有异步导出。旧壳不支持成功反馈时拒绝清空并说明原因，避免在保存结果未知时删除。

本次是功能开发与验证，不移动已发布的 v0.3.0 标签，不另行发布 APK。
