# 归约顺序设计

core.findRedex 保留原 path 参数，增加第三参数 strategy；step/normalize 增加可选 strategy，默认 normal。迭代扫描和不可变子树 redex 缓存保持，应用序优先检查函数/参数的内部 redex，再返回当前应用。

App state.strategy 对应运行区 select。render/step/run 全部传递策略。运行中切换取消旧计时器并按当前速度重新安排。手动指定 stepAt 不受策略限制。

view.strategy 为可选 normal/applicative，旧档默认为 normal。session.paths 的 null 仍表示历史中的正规序步骤；应用序步骤存明确路径，与手动项共用既有 v3 重放机制，避免切换偏好改变旧历史。不增加压缩、步数或线路限制，不新建APK Release。
