# 自定义输入形式

- **Status**: COMPLETE
- **Approved**: 2026-11-02 用户明确要求自定义数字的输入写法
- **Type**: feature

## 需求与设计

每种编码可配置包含一个`{n}`的输入模板，例如丘奇数的`C{n}`、列表小数的`{n}d`、自定义编码的`[{n}]`。模板只改变输入记法，不改变数值域或转换算法；标准`数字_编码名称`始终可用，无后缀仍使用当前编码。匹配完整字面量，保持普通变量不被部分改写；与绑定变量同形的字母数字写法在绑定作用域中仍表示变量。冲突或不合法模板清楚报错，不猜测含义。

输入形式编辑器默认收起，选择当前编码后设置模板、预览例子、保存或恢复默认。内置编码设置和自定义编码模板随存档保存。模板修改保留转换函数和对照表；自定义编码改名保留显式模板。主图继续手动转换，后台数字编码可识别新记法。
