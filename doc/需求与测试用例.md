# Lambda 线路实验室：需求与测试用例

版本：0.1.0；日期：2026-10-09；状态：已确认实现范围。

## 目标与用户流程

输入 Lambda 表达式 → 点击转换 → 查看 John Tromp 图示 → 单步或自动执行 β 归约。额外提供自由实验与五个入门挑战，挑战通过归约结果的 α 等价判定。

## 功能规则

- 快捷栏在光标/选区插入 λ、变量、点、括号与常用完整模板。支持反斜杠代替 λ、多参数简写 λx y.x、空格分隔的变量名。
- 文法为标准无类型 Lambda 演算；应用左结合，λ 的作用域尽量向右。xy 是一个变量，x y 是两个变量的应用。
- 图示采用 Tromp 标准样式：抽象横线、绑定变量的竖线、连接左右子项最左变量的应用横线。自由变量使用带名字的虚线竖线扩展，不伪装成闭项。
- 执行采用左最外的正常序 β 归约，包括 λ 内部；替换避免变量捕获。显示当前式、下一归约位置、轨迹、步数和 Church 数/布尔解释。
- 提供转换、单步、运行/暂停、回退、重置、速度、缩放、适配与 SVG 导出。编辑源式后停止运行，并提示重新转换。
- 无限循环及超大表达式具有可解释的停止原因；限 1500 输入字符、300 语法深度、4000 AST 节点和每轮最多 200 次归约。
- 本地保存草稿和已完成关卡；浏览器禁用存储时仍可使用。
- 桌面双栏，移动端纵向排列；操作可用键盘、鼠标及触摸。
