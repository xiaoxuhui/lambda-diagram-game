# Lambda 线路实验室：需求与测试用例

版本：0.1.0；日期：2026-10-09；状态：已确认实现范围。

## 目标与用户流程

输入 Lambda 表达式 → 点击转换 → 查看 John Tromp 图示 → 单步或自动执行 β 归约。额外提供自由实验与五个入门挑战，挑战通过归约结果的 α 等价判定。

## 功能规则

- 快捷栏在光标/选区插入 λ、变量、点、括号与常用完整模板。支持反斜杠代替 λ、多参数简写 λx y.x、空格分隔的变量名。
- 文法为标准无类型 Lambda 演算；应用左结合，λ 的作用域尽量向右。xy 是一个变量，x y 是两个变量的应用。
- 图示采用 Tromp 标准样式：抽象横线、绑定变量的竖线、连接左右子项最左变量的应用横线。自由变量使用带名字的虚线竖线扩展，不伪装成闭项。
- 执行采用左最外的正常序 β 归约，包括 λ 内部；替换避免变量捕获。显示当前式、下一归约位置、轨迹、步数和 Church 数/布尔解释。
- 提供转换、单步、运行/暂停、回退、重置、速度、缩放、适配与 SVG 导出。编辑源式后停止运行，并提示重新转换。
- 无限循环及超大表达式具有可解释的停止原因；限 1500 输入字符、300 语法深度、4000 AST 节点、展开变量名文本 30000 字符和每轮最多 200 次归约。
- 本地保存草稿和已完成关卡；浏览器禁用存储时仍可使用。
- 桌面双栏，移动端纵向排列；操作可用键盘、鼠标及触摸。

## 0.2.0：函数库与状态存档

- 用户 2026-10-09 要求新增自定义函数、删除函数、保存进度和当前状态。
- 函数以英文字母开头的名称和 Lambda 表达式定义；可调用现有函数，也支持自由变量；展开避免变量捕获，λ 绑定的同名变量优先。新增同名函数报错，不静默覆盖；自引用提示用显式不动点组合子。
- 定义在保存时展开现有函数，后续删除被引用函数不会破坏已保存定义。已经转换的运行式也保留当时的定义；再次转换采用最新函数库。
- 增加「使用当前式」「新增函数」和逐项「插入」「删除」。最多 32 个函数，函数库合计最多 16000 个节点、120000 个变量名字符。
- 自动保存完整状态；提供「保存当前状态」「恢复已保存状态」「导出存档」「导入存档」。存档包括草稿、函数、起始 AST、归约步数、模式、关卡进度、速度、缩放和展开状态。恢复后自动运行保持暂停。
- 采用 v2 存档并兼容读取 v1 草稿/通关进度；旧存档不会被首次初始化意外覆盖。显式存档与自动存档分开，自动保存不会覆盖用户手动设置的恢复点。
- 导入先完整校验，再替换现场；非法/超限存档不改变现场。无法使用浏览器存储时提示用户导出文件。
