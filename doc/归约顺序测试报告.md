顺序选择的实际操作与验收：

1. 输入 `(λx.x) ((λy.y) z)`，默认正规序高亮外层；切换应用序后高亮内部，分别单步得到 `(λy.y) z` 和 `(λx.x) z`。
2. 输入 `(λx.(λa.a) x) ((λy.y) z)`，应用序依次归约函数体、参数、外层。
3. 正规序丢弃未使用的 Ω 参数，应用序持续运行至少三步，直到手动暂停，无重复状态自动暂停。
4. 自动运行等待下一步时切换顺序，再调整速度，运行继续且下一步采用新顺序。
5. 混合顺序后刷新、保存、恢复、导出、导入和回退，逐帧路径及当前偏好一致。
6. 清空复位为正规序，导出的备份恢复应用序；旧档缺少偏好时默认正规序。
7. 手动点选外层横条可以覆盖应用序的自动选择。
8. 390 像素手机视口可操作选择器且无横向溢出；独立离线 HTML 行为一致。
9. 全程无页面异常。
